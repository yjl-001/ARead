# 注释生成

## 为生成的每个类添加注释

类注释模板

```
/**
 * @class {ClassName}
 * @description {类的描述}
 * @param {参数类型} {参数名} {参数描述}
 * @returns {返回值类型} {返回值描述}
 */
```

## 为生成的每个函数添加注释

函数注释模板

```
/**
 * @function {functionName}
 * @description {函数的描述}
 * @param {参数类型} {参数名} {参数描述}
 * @returns {返回值类型} {返回值描述}
 */
```

## 为函数中的关键逻辑进行注释说明

在函数的关键逻辑处添加注释，说明其实现的功能和逻辑。
